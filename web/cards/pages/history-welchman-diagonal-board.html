How did linking wires in pairs make the Bombe give fewer false answers?

Each square is one guess: row letter plugged to column letter.

Tap a square to test that plugboard guess.

Guessing R is plugged to Y is the same guess as Y plugged to R. Welchman wired each such pair together, so one live wire makes its twin live too. The same input rules out more plugboard swaps: about 4 stops to check instead of 100.

WHAT TO KEEPWire together facts that must agree, and false answers die faster.
