Why was Hitler's own cipher machine so much harder to break than Enigma?

10¹⁷⁰ keys, not 10²³

Enigma had about 10²³ possible keys. Hitler's machine had 10¹⁷⁰: more than the number of atoms in the observable universe, squared. Trying every key was mathematically impossible.

Each square is one digit. Enigma's key count fills the grey ones. Drag to guess where Hitler's machine ends.
