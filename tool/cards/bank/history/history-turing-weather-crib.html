How did weather reports help Alan Turing break Enigma?

An Enigma key never lights its own lamp, so a letter can't encrypt to itself. That rules out every spot but one for the guessed weather report.

There, the letter pairs chain into a loop: R→E→T→R. Turing wired machines into that same loop to test settings: only correct ones bring R back to R.
