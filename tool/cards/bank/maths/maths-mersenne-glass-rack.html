EXTEND THE CURVE

Mersenne primes 2ᵖ−1 get rarer as p grows. Do they run out?

Each step is one more prime. Drag the dot: where is the count far to the right?

They never run out, if the conjecture is right.

The Lenstra–Pomerance–Wagstaff conjecture predicts how many Mersenne primes should appear for each size of p, and it fits the actual data remarkably well. It implies there are infinitely many, so infinitely many even perfect numbers. But a conjecture is not a proof.

WHAT TO KEEP Rarer and rarer is not the same as running out.
