HALTING PROBLEM

Why can’t we predict if a program will halt on a given input?

Suppose a program H can tell whether any program halts on its input.

Either way, H is wrong.

Whatever H predicts, H+ does the opposite. So no program like H can exist.

Build H+ in two taps, then test H.

WHAT TO KEEPNo program can predict, for every program, whether it will halt.
